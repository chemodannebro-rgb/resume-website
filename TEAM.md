# Команда

| Роль | Функционал |
|---|---|
| **Владелец проекта** | Приоритизация задач, финальное решение по контенту резюме и позиционированию, go/no-go по крупным изменениям (например, переход на React/3D) |
| **Frontend/UX Engineer** | Вёрстка и логика сайта (сейчас — статический HTML/CSS/JS, при переходе — компонентная архитектура), адаптивность, тёмная тема, доступность |
| **Design/Visual Engineer** | Визуальный стиль, анимации, 3D-эффекты и их влияние на производительность/читаемость, отбор компонентов из внешних библиотек (например, 21st.dev), проверка UI/UX-решений через skill `ui-ux-pro-max` (доступность, типографика, цвет, анимация) |
| **Content/Copy** | Тексты резюме, кейсов, описаний инструментов — точность фактов (роли, метрики, даты), консистентность тона |
| **Release Engineer** | Сборка и деплой (GitHub Pages, домен `lisinaleksei.tech`, CNAME), проверка, что прод не ломается после изменений |
| **Code Reviewer** | Чек-лист перед мёржем: код рабочий и проверенный, нет мёртвого кода, стиль соответствует остальному проекту |
