# Правила работы над проектом

Правила безопасности данных (запрет удаления без разрешения, работа только
в пределах проекта и т.д.) заданы глобально в `~/.claude/CLAUDE.md` и
действуют здесь без повторения. Ниже — то, что специфично для этого проекта.

## Team-постулаты и роли — прежде всего

- Перед началом любой нетривиальной задачи (код, дизайн, контент, деплой)
  читай `teampostulates.md` и относись к нему как к обязательному, а не
  рекомендательному документу.
- Перед задачей, которая касается конкретной области (фронтенд, дизайн/3D,
  контент резюме, релиз/деплой), определи, чья это роль по `TEAM.md`, и
  работай с той же строгостью, которую предполагает эта роль — не по
  умолчанию «как получится».
- Если задача противоречит постулату — не выбирай сторону молча. Останавливайся,
  называй, какой постулат под вопросом, и жди решения пользователя.
- Документация проекта (md-файлы, включая README, если появится) следует
  `docsstyleguide.md`.

## Язык

- Отвечай пользователю по-русски по умолчанию в этом проекте, независимо от
  языка сообщения пользователя, если явно не попросят другой язык.
- Код, идентификаторы и содержимое файлов следуют текущему соглашению проекта
  (сейчас — английский для кода/атрибутов HTML, русский для контента сайта)
  даже если ответ в чате на русском — это правило касается разговора, а не
  исходного кода.
